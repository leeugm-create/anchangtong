# 案场通 · 案场客户管理系统（第一阶段演示版）

给江河序案场用的客户管理系统，PWA 网页版：手机"添加到主屏幕"就能当 App 用，电脑浏览器直接打开是完整后台。

## 怎么跑起来

1. 电脑上装 Node.js（18 以上就行，去 nodejs.org 下一个）
2. 把这个文件夹拷到电脑上，终端进到文件夹里，运行：

```
node server.js
```

3. 浏览器打开 http://localhost:3000

手机和电脑连同一个 WiFi 的话，手机浏览器打开 `http://电脑IP:3000` 也能用（比如电脑 IP 是 192.168.1.5，就打开 http://192.168.1.5:3000）。

## 现在能用的功能（第一阶段）

- 来访登记 / 来电登记（手机号重复会自动拦下，防撞单）
- 客户库：搜姓名/手机号，按渠道、意向、状态筛
- 客户详情：写跟进记录（自动更新最后跟进时间）
- 15 天公池：超过 15 天没跟进的客户自动流入公池，谁都能抢
- 后台（销售经理）：看全部客户、判客（改归属，原因留档）、改客户资料（改手机号自动留痕）、软删除/恢复、操作日志
- 数据：**每天第一次启动自动备份一份数据库**（backups 文件夹，最多留 30 份）；后台可一键导出 Excel、可下载整个数据库文件

## 数据存在哪

`data/anchangtong.db` —— 一个 SQLite 文件，**整个拷走就是备份**。
演示版跑在自己电脑上；正式上线时把这个文件夹放到阿里云/腾讯云的服务器上跑 `node server.js` 就行，数据一直在自己手里。
